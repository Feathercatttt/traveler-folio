# 旅人手札 v0.24.0 · 统一本地插件

**本项目由 AI 辅助生成与维护。** 更新前导出角色备份；Android 使用原签名覆盖安装，不要先卸载。

## 安装与更新

Windows 完整解压安装包后运行 `旅人手札.exe`，不要只复制 EXE。所有枭熊功能均由包内 `owlbear` 文件夹提供：角色速查、动画骰、历史与回放、先攻、目标选择、演出、怪物图鉴、生命速调和场景工具。插件与手札版本一致，应用更新包也包含同一套文件。

每位玩家先打开新版 EXE，再进入枭熊房间；DM 在自己的 EXE 开启时，安装并启用下面两个地址：

| 插件按钮 | 安装地址 |
| --- | --- |
| 角色速查 | http://localhost:17632/manifest.json |
| 跑团工具 | http://localhost:17632/tools-manifest.json |

**停用此前的 GitHub 线上扩展，只启用上述两项。** 更新 EXE 后刷新枭熊房间，重新加载新版插件。旧的 GitHub 安装地址只作为迁移兼容入口，指向同一套 localhost 文件，不再运行另一套线上代码。

新版 EXE 会核对本地服务版本。同一安装目录里仍运行的旧版手札桥接会被替换；其他目录的服务不会被强行关闭，若占用端口会提示先退出旧版。静态文件不缓存，并带版本参数，避免更新后混用旧页面与新脚本。

GitHub 保留源码、EXE/APK/HTML 下载、功能说明与签名自动更新清单。EXE 的更新仍沿用镜像线路与签名校验。APK 包含完整手札和规则记录；枭熊本地插件服务由电脑端 EXE 提供。

## 本次修复

- 本地服务原先漏掉 `initiative21.css`、`theatre21.css`，造成先攻黑底和大头像布局失控。现在统一提供公开静态资源，并核对页面引用，背景完全透明，开始战斗后头像仍固定在条目尺寸内。人数多时横向滚动。
- 直播控制条与立绘处在同一个全屏交互层，不再被立绘层挡住。直播中可直接拖动立绘；每张立绘的 − / ＋ / 重置按钮或悬停滚轮可缩放。位置和尺寸经 DM 校验后同步给所有人。
- 同层控制条可切换差分，单击上下场、右键下场，并随控制角色数缩小宽度；DM 始终能点击“结束直播”。结束后恢复地图操作。没有电影黑条和对话框。
- 本地小卡点击检定进入最终确认，支持正常 / 优势 / 劣势，保留额外加值和一次性骰子。确认后使用内置动画骰，结果出现在右下角摘要、历史和回放中。历史合并角色检定与本机工具骰子的记录。
- 怪物图鉴也在本地工具中：从完整手札制作与编辑，插件读取后放置。每只地图怪物拥有独立的 Stat Bubbles 生命值、临时生命和 AC，模板不回写实例。

## 规则记录

完整手札中的“使用说明”改为“规则”。可以创建独立规则条目，填写标题、分类和正文，搜索、查看、编辑或删除。取消编辑不保存修改；条目自动保存，完整 JSON 备份包含这些规则。

移除了完整手札里重复的“枭熊小卡”按钮；在枭熊点击角色速查插件即可打开小卡。小卡支持原生固定、尺寸切换和关闭。
