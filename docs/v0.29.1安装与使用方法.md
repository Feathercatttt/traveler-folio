# 旅人手札 v0.29.1

本项目由 AI 辅助编写和维护。

## 安装与更新

- Windows：解压后打开“旅人手札.exe”。缺少 WebView2 时，完整包附有微软离线安装器。
- Android：覆盖安装新版 APK，保留原有数据。
- 更新入口：设置 → 检查更新。支持切换下载线路，并校验签名和文件。
- 离线网页：直接打开“旅人手札.html”。扫码和枭熊联动需要本机桥接，EXE 会自动启动它。

## 枭熊与手动同步

每位玩家打开自己电脑上的 EXE。DM 在房间安装：

| 按钮 | 安装地址 |
| --- | --- |
| 角色速查 | http://localhost:17632/manifest.json |
| 跑团工具 | http://localhost:17632/tools-manifest.json |

更新 EXE 后刷新枭熊房间。插件随 EXE 更新；GitHub Pages 作为安装说明与兼容入口。

绑定地图 token 时，自动把 token 名称和地图上的名称标签设为对应角色 / 召唤物名字；改名后自动同步，其他角色卡的绑定也会更新。解绑后保留最后的名字并停止同步。

小卡显示本机打开的角色卡，不读取 DM 的 EXE。若显示旧数据，点击小卡顶部“同步本机”：它会重新连接本机服务，请求 EXE 发布最新数据，并同步自己的绑定棋子。没有收到 EXE 确认会明确报错，可重新点击。

点击公式先打开草稿，可改公式、临时加值、优势/劣势，再确认投骰。目标选择与伤害掷骰均不自动扣血。

## 召唤物借用主卡装备

1. 打开召唤物 → 编辑 → 装备栏，勾选“开启此卡装备栏”。
2. 从主卡背包搜索物品，在装备位选择。只能借用背包实际拥有的武器或装备。
3. 背包数量表示总数；主卡穿戴和每个召唤物各占用一件。只有一把剑时不能同时装备给主卡与召唤物。卸下或移除召唤物后释放可用数量。
4. 支持头盔、衣服、腰带、裤子、鞋子、五个饰品、主副手。双手武器需要空出副手。
5. 装备的 AC、属性影响与武器公式按召唤物自身数据计算；修改主卡物品会同步更新。可以展开查看装备数值来源。
6. 模板只是预设，每次实际召唤才占用数量。取消编辑不改动现有装备。减少背包总数时，多出的借用会解除。
7. 旧版私有装备记录会保留在“旧版独立装备记录”中；能对应主卡物品的装备会自动转为借用。

怪物仍使用自己的物品与装备库：完整怪物卡 → 编辑 → 装备栏。放置或覆盖地图怪物时使用计算后的数据，场上怪物生命独立记录在 Stat Bubbles。

## 电脑与手机扫码互通

1. 两端连接同一 Wi-Fi。
2. 电脑：设置 → 互通 → 整卡互通 / 接收导入 → 开启扫码互通。
3. 手机 APK：设置 → 互通 → 整卡互通 / 接收导入，选择“扫描并接收电脑数据”或“扫描并发送手机数据”，授权相机后扫描。
4. 导入前查看预览并确认。二维码有效 20 分钟；关闭互通窗口会结束分享。

只分发物品、特性或法术：在互通界面搜索、筛选并勾选卡片，分发已选内容，再保存文件或开启扫码。独立卡库不覆盖角色生命、背包数量和笔记。导入前自动保留恢复点。

若手机连不上，检查两端 Wi-Fi、电脑防火墙是否允许手札局域网连接；也可直接传送 .folio 文件。

## 常用入口

| 功能 | 位置 |
| --- | --- |
| 风格、导入导出、互通、桌面浮窗、打印、更新与版本号 | 设置 |
| 特性 / 物品 / 法术的小收藏窗 | 收藏库 |
| 大页面排列与编辑卡片 | 藏书架 |
| 怪物完整卡与分类筛选 | 怪物图鉴 |
| 定位到卡片或检定 | 大卡搜索；检定结果旁另有掷骰按钮 |
| 村规条目 | 规则 |

地图怪物图片流程：上传立绘 → 选图并绑定 → 预览放置；也可覆盖选中 token 的怪物数据。场上列表可改名称、HP、临时 HP、AC、DC，并快速定位。
