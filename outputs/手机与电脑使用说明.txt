# 旅人手札 v0.25.1 · 安装与使用

**本项目由 AI 辅助生成与维护。** 更新前导出角色备份；Android 使用原签名覆盖安装，不要先卸载。

## 安装与更新

Windows 完整解压后运行 `旅人手札.exe`，不要只复制 EXE。已安装用户也可在应用内检查更新。所有枭熊功能来自 EXE 同包的 `owlbear` 文件夹，并随手札更新。

每位玩家先打开自己的 EXE，再进入枭熊房间。DM 安装并启用两个本地地址：

| 插件 | 地址 |
| --- | --- |
| 角色速查 | http://localhost:17632/manifest.json |
| 跑团工具 | http://localhost:17632/tools-manifest.json |

更新后退出旧 EXE，打开新版并刷新房间。本次跑团工具入口改为原生面板；若仍显示旧的中转按钮，请 DM 移除并重新添加“跑团工具”地址一次。不要同时启用旧的重复扩展。GitHub Pages 保留安装说明及兼容地址，不运行独立的线上功能版本。

主面板与小卡一样，通过插件按钮打开、再次点击收起；也可用右上角 × 关闭。取消主面板拖动。地图工具区另有先攻、生命速调、怪物图鉴与演出直播按钮。

## 先攻

DM 在 token 右键菜单选“加入旅人先攻”。先攻条固定在顶部中央下方且不能拖动，头像扩大到 72px，人数较多时横向滚动。头像下方有原骰点/最终值；若 token 设有可见的 Stat Bubbles 生命值，还会显示血条。玩家不会因此看到 DM 隐藏的血量。

右键头像可“重骰先攻”或“退出战斗”。重骰仍会打开最终确认窗口，可在那里选优势/劣势、修改公式或临时加值，确认后才投骰。退出战斗只移除当前先攻条目，保留地图棋子。玩家可在准备阶段重骰自己的先攻；退出条目与战斗中的重骰由 DM 操作。

结束战斗默认清空先攻列表。绑定角色卡的先攻值继续跟随角色卡；占位符仍由 DM 添加。保留战斗结束的角色事件。

## 怪物图鉴与场上列表

在完整手札的“怪物图鉴”制作或导入怪物，填写种族、分类、等级、熟练加值并上传立绘。图鉴不会添加到玩家角色卡。

在枭熊点击独立“怪物图鉴”工具按钮。初次不显示所有怪物；输入名称，或选择种族/分类/等级/熟练加值后才出现结果。点“放置”或拖拽立绘入场景。已上传立绘直接用于棋子，并转换为最多 256px、有大小限制的 WebP；图片数据随棋子共享，其他玩家不需要访问 DM 的本地图片服务。没有立绘的模板才会要求从枭熊图片库选图。更换模板立绘后刷新图鉴，下次放置使用新图；已有棋子保持原样。

同名新怪物默认叫“名称 1”“名称 2”等，跳过已占用的编号。在图鉴点击“场上怪物”，或在跑团工具选“怪物列表”，打开单独列表。每只怪物占一行，可直接修改地图名称、HP、临时生命、AC、DC；⌖ 定位，⋯ 查看资料。改名也会更新该怪物的先攻条名称。

每只怪物的生命值保存在其 Stat Bubbles 数据中，与图鉴模板及其他实例分开；扣血/回血仍手动操作。

## 演出

在跑团工具“演出”中创建角色，上传立绘与差分，勾选列入直播并分享控制权限。可按角色名称搜索，筛选全部可控、列入直播、正在上场、我创建的。点击“查看上场名单”只在当前界面筛选，不会打开第二个浮窗。

准备好后点击地图上的“演出直播”按钮，或编辑页的“开启直播”。未准备立绘时会先打开演出设置。只有一个直播层和它内部的控制条；没有电影黑条、对话框或旧的独立直播浮窗。

直播控制条可搜索和筛选候场/场上角色，单击上下场、右键下场、选择差分。DM 与授权玩家可直接拖动上场立绘；− / ＋ / 重置或滚轮缩放，位置与尺寸同步。按用户选择，直播层持续接收鼠标，会遮挡地图操作。

即使搜索没有结果、删除了所有演出角色，DM 的“结束直播”按钮也仍存在。点击后关闭直播层并恢复地图操作，随后可再次开启。直播控制条不提供单独关闭入口。

## 骰子与角色资料

角色小卡自动连接本机手札。公式先进入确认窗口，支持优势/劣势、临时加值、目标与多目标投骰模式；确认后播放内置动画并留下历史/回放。临时骰子影响进入最终基础公式。目标不自动扣血。

完整手札的“规则”支持创建、分类、搜索、编辑与删除村规条目，并进入完整 JSON 备份。手机 APK 内置同一版本手札；枭熊本地服务由电脑 EXE 提供。

## 本轮验证范围

使用实际本地 HTTP 服务、正式打包文件和真实 Owlbear SDK，在模拟宿主中测试原生面板重复开关、30 个高立绘先攻条、右键菜单、血条、结束清空、图鉴筛选/放置/编号、跨来源读取棋子图片、场上改名与独立 HP、演出搜索/删空/结束/再次开播、内置动画/优劣势/历史。

Windows 原生启动、网页内核缺失时的恢复入口、同目录旧服务替换，以及 APK 版本/原签名/嵌入页面一致性已检查。真实枭熊多人房间与实体 Android 尚未进行本轮端到端验收。
