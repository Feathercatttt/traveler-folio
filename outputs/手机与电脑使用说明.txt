# 旅人手札 v0.26.0 · 安装与使用

**本项目由 AI 辅助生成与维护。** Android 使用原签名覆盖安装；Windows 完整解压运行，不要单独复制 EXE。更新前可在设置中导出备份。

## 新导航

| 入口 | 用途 |
| --- | --- |
| 我的冒险者 | 切换角色、回到角色卡 |
| 收藏库 | 小窗口切换特性/物品/法术，并切换是否只看已收藏 |
| 藏书架 | 替换角色卡的大页面，网格整理、制作、编辑三类卡片 |
| 召唤物卡库 | 管理召唤模板 |
| 职业与种族 | 来源配置与文档资料 |
| 怪物图鉴 | 替换角色卡的大页面，制作/编辑怪物和立绘，不能添加到玩家卡 |
| 设置 | 风格、导出/导入、互通、桌面浮窗、打印、更新及版本 |
| 规则 | 独立编辑村规条目 |

藏书架和怪物图鉴的右上角返回/关闭会恢复当前角色卡。点击左侧角色也会回到角色页。浏览收藏库不切换当前角色；从藏书架打开小收藏库后，关闭小窗会恢复藏书架。两者共用同一套卡片数据，三类库内均不再提供怪物图鉴跳转入口。

手机底部使用四个紧凑入口：收藏库、藏书架、图鉴、设置。设置内“角色速查”使用手机原有速查面板，不显示浏览器置顶等桌面专属入口。

## 搜索与收藏

大卡的属性总览、特性、物品、法术页均有搜索框。可输入名称的一部分，也支持有序的非连续字符，例如“魂赎”可匹配“魂镰之赎”。搜索也匹配标签、描述和部分英文/属性代码。

点击卡片结果，会定位、高亮并展开对应卡片；若它被“只看已收藏”隐藏，会先显示全部再定位。点击技能、属性、豁免等检定结果只定位，不投骰。结果旁的骰子按钮才进入原有检定流程：连接枭熊时先开确认页，否则使用本地结果。上下键选择结果、回车定位。

属性总览还可搜索生命值、临时生命、上限、护甲、熟练加值、速度、法术 DC 和被动技能值。检定搜索从其他页进入时，会先切换属性总览再定位。

特性、物品、法术页的“只看已收藏”分别记住本次会话的筛选状态。卡片底部可直接收藏/取消收藏。收藏记录仍为原有全局卡库记录，可用于多个角色；筛选不会删除或卸下卡片。

**这套搜索定位只应用于手札大卡。枭熊小卡不增加跳转步骤，保持原有快速检定。**

## 特性编辑

基本信息包含名称、分类、特性分栏、行动/材料消耗、完整规则正文、风味文字。其他规则信息、次数恢复、召唤物、公式、多效果仍可分别展开。

在“属性增减”中勾选“设置可选属性加成”后，才出现选择组。可勾选角色允许选择的属性、编辑加值或添加多组。编辑过程中临时取消再勾选会保留草稿；取消并保存则移除该可选加成。亚种/形态的选择限制仍可独立设置。

原“规则备注/自动化说明”界面已移除，旧数据保留在备份中。末尾“备注”只供编辑时阅读；里面可选指定主职业或副职业作为次数/数值成长来源。不指定则沿用自动来源。编辑备注不会显示在玩家卡上，并随 JSON 备份保存。

特性收起时，只显示一行风味文字；无风味时截取规则正文。展开详情后，短预览隐藏，完整风味以引文显示、规则正文正常显示，避免重复。数值影响继续随详情展开和收起。

## 备份、互通、打印与更新

在左侧“设置”进行导出、导入及互通。互通仍支持电脑显示二维码、手机 APK 调用相机扫描，以及按条目分发卡库。打印前会回到角色卡，避免打印藏书架或怪物仓库。

EXE：设置 → 应用与更新。APK：设置 → 检查更新。沿用原有镜像下载和签名校验，公共镜像可用性仍取决于网络。

## 枭熊插件

每位玩家先打开自己的 EXE，再进入枭熊。DM 在 EXE 开启时安装并启用：

| 插件 | 地址 |
| --- | --- |
| 角色速查 | http://localhost:17632/manifest.json |
| 跑团工具 | http://localhost:17632/tools-manifest.json |

更新 EXE 后刷新房间。插件与手札同包更新。保持 v0.25 的原生小卡、固定先攻、独立图鉴/演出工具按钮、手动生命速调与内置骰子流程。

先攻头像右键可重骰或退出战斗，结束战斗清空列表。地图图鉴先筛选/搜索，再使用手札立绘直接放置，并自动编号；场上怪物列表可单独编辑名称、HP、临时 HP、AC、DC。怪物实例生命独立记录在 Stat Bubbles。

演出只有一个直播层和同层控制条，支持搜索、名单筛选、差分、授权移动/缩放；空名单仍可结束。所有目标/伤害功能只标记和报结果，不自动扣血。
