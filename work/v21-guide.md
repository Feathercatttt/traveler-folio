# 旅人手札 v0.21.0

AI 辅助生成和维护的代码。请先导出一次角色备份，再更新。数据格式仍为 10，APK 保留原签名。

## 安装与更新

- Windows v0.20：在软件顶部“更新”检查并下载，确认后保存并重启。首次安装选完整包，缺少 WebView2 时点击随包离线安装器；已有内核可用轻量包。
- Android：在“更多 → 检查更新”下载并覆盖安装，也可直接安装新 APK。不要卸载旧版。
- 纯 HTML：本地打开新版 HTML，角色仍使用原浏览器数据。建议先导出备份。
- 自动更新保留三条 HTTPS 镜像、失败换线、自定义镜像与签名校验。公共线路可能限速或调整，不能保证所有中国运营商永久可达。

## 枭熊改为线上安装

安装说明页：https://feathercatttt.github.io/traveler-folio/

DM 添加并在房间启用两个扩展，各占一个按钮：

| 按钮 | 安装地址 |
| --- | --- |
| 旅人手札 · 角色速查 | https://feathercatttt.github.io/traveler-folio/manifest.json |
| 旅人手札 · 跑团工具 | https://feathercatttt.github.io/traveler-folio/tools-manifest.json |

停用旧的 localhost 扩展，刷新枭熊页面。DM 换电脑仍使用相同的线上地址。

骰子、先攻、演出与场景工具不依赖 EXE。读取个人角色或本地图鉴时，使用 v0.21 或以上 EXE，在小卡点击“连接本机角色卡”。若浏览器限制插件访问本机，点击“连接窗口”，保留弹出的本机窗口并可最小化。关闭小卡不会断开该连接，关闭连接窗口会断开本机资料。

小卡选择角色 / 召唤物，地图选中对应棋子，点击绑定。角色与召唤物的 HP、临时生命和 AC 继续联动 Stat Bubbles，状态继续联动 Marked。GitHub Pages 不保存个人角色与怪物库。

## 本次修改

| 功能 | 用法 |
| --- | --- |
| 骰子摘要 | 投骰后右下角显示检定名称、公式、点数明细、结果与玩家；最近三条可滚动查看，12 秒后收起。完整记录在“骰子 → 历史”，可回放。 |
| 优势 / 劣势 | 确认页切换正常、优势、劣势；保留原加值与其他骰子。不含单次 d20 的公式不会被错误替换。 |
| 目标 | T 点击多选目标。成功投骰后清空目标与连线；取消和失败保留。多目标伤害仍只报告结果，不自动扣血。 |
| 浮窗 | 拖动标题栏移动，右下角拖动缩放，× 关闭。大小和位置保存在本机；右下角手柄也支持方向键，Shift 加速。 |
| 生命速调 | 心形按钮打开默认 280×172 小窗，只跟随地图当前选择。输入数值扣血 / 回血，伤害先消耗临时生命。切换棋子会清空上次输入，避免误操作。 |
| 怪物图鉴库 | 完整卡顶部或藏书架“怪物图鉴”制作 / 编辑 / 复制 / 导入怪物，上传立绘，配置六维、HP、AC、DC、技能和多行动。不能添加到玩家角色卡。 |
| 怪物放置 | 跑团工具“怪物”连接并刷新本地图鉴。首次点击“准备立绘”，上传后在枭熊图片选择器选入一次；之后可以直接放置或把缩略图拖入地图。没有立绘也可从图片库选择 token。 |
| 怪物实例 | 每次放置单独保存行动资料，HP、临时生命、AC 单独记录在 Stat Bubbles。地图实例表每只一行，可改 HP / 临时 / AC / DC 并定位；改模板不会回写已放置的怪物。 |
| 独立演出角色 | “演出 → 创建角色”，上传立绘并在图片库选入，可添加、命名和删除差分。角色与 token 无关。DM 勾选“列入直播”，分享玩家控制权限。 |
| 演出直播 | 开启直播后出现上场小窗。点击立绘上场，右键下场，或使用下场按钮；选择差分 / 表情与立绘特效。最多同时 8 位。地图滤镜使用枭熊原生效果，关闭直播会清除。 |
| 先攻 | 采用 obr-suite 的横向肖像、准备与战斗阶段、原骰 / 最终值显示、玩家结束回合、DM 前后回合与手动排序结构，投骰走手札确认流程。绑定角色使用卡片先攻；未绑定默认 0，怪物用模板值。DM 可改数值、恢复卡值、添加占位符。 |
| 移除时停 | 不再拦截玩家画布。同步镜头、传送门仍保留。 |

手动排序：先点一张先攻卡，再点目标卡插入；按住 Shift 点击交换位置。数值保持不变；按先攻排序可恢复数值顺序。更改加值会保留原 d20 结果并重新计算最终先攻。

## 验证范围

本版运行了真实本机桥接、Edge 浏览器、模拟多玩家、跨站 iframe 连接、窗口拖动 / 缩放 / 关闭、Windows 原生及 Android 模拟器检查。未登录真实枭熊多人房间验证，也未覆盖所有 GPU 与实体手机；原生地图滤镜和官方图片上传选择器仍需要真实房间反馈。源码中的 work/v21-*-report.json 记录各项结果。

原生窗口和资源操作按 [枭熊官方 API](https://docs.owlbear.rodeo/extensions/apis/) 实现；先攻参考 [FullPeople/obr-suite](https://github.com/FullPeople/obr-suite)，动画及改编代码保留 GPL 许可与来源说明。

## GitHub 维护与发布

插件源码位于 `outputs/owlbear/src`。推送到 main 后，GitHub Actions 会按锁定依赖构建脚本，并只发布静态插件白名单文件到 Pages；安装地址保持不变，玩家刷新枭熊即可加载。个人存档、本机桥接服务和签名私钥不会部署到 Pages。

EXE / APK 从 GitHub Releases 发布，通过已签名的 `updates/stable.json` 检查更新。先上传并验证安装包，再发布对应版本清单；原 APK 签名和更新签名私钥需由维护者保留，不在公开仓库提供。
