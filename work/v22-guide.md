# 旅人手札 v0.22.0 · 怪物图鉴与工具窗口更新

**本项目由 AI 辅助生成和维护。** 更新前请导出角色备份。此版本保留角色数据结构；Android APK 使用原签名，可覆盖安装。

## 怪物图鉴

完整卡左侧的“怪物图鉴”入口现在取代“村规手册”。点击后从右侧打开独立怪物仓库，不会把怪物混进玩家角色卡。

DM 可以在仓库中制作、导入和编辑怪物卡。卡片编辑器按六个区块组织：基础属性、豁免、熟练加值、特性、动作、法术；可以上传立绘。怪物可填写物种、分类、等级和熟练加值，仓库可按这些字段筛选，也能搜索名称。点击列表条目可查看完整怪物卡，再从详情返回编辑。

枭熊“跑团工具 → 怪物”读取本机图鉴后，可准备立绘并放置多个 token。每只地图怪物的 HP、临时 HP、AC 与 DC 独立记录；编辑模板不会覆盖已经放置的实例。

## 其他更新

- 普通工具页里的先攻卡片现在使用正常文档布局，避免横条样式覆盖导航；独立顶部横向先攻条保持原有展示和交互。
- 生命、演出、怪物等浮窗支持标题栏拖动、右下角缩放和关闭；生命速调默认跟随地图当前选中的 token。
- 演出保持独立角色、差分选择、直播名单与原生滤镜；开始直播时上场名单保持打开，结束直播后关闭。
- 继续支持确认后掷骰、优势 / 劣势、掷骰结果摘要、目标投骰后清除、手动扣血，以及 Stat Bubbles 联动。
- Windows 完整包附带微软签名的 WebView2 Runtime 安装器。缺少运行时会给出安装或在浏览器中打开本地卡片的选项；不会静默安装系统运行时。

## 枭熊线上安装

DM 在枭熊扩展管理中添加两个 GitHub Pages 地址并在房间启用。DM 换电脑仍使用相同地址；停用旧 localhost 扩展后刷新房间。

| 独立按钮 | 安装地址 |
| --- | --- |
| 旅人手札 · 角色速查 | https://feathercatttt.github.io/traveler-folio/manifest.json |
| 旅人手札 · 跑团工具 | https://feathercatttt.github.io/traveler-folio/tools-manifest.json |

角色与怪物资料保存在本机，不会上传到 GitHub Pages。要让插件读取本地图鉴，请打开 EXE 并在枭熊小卡中连接本机角色卡。制作的怪物不会添加到玩家角色卡，只能在图鉴查看或由 DM 放置到场景。

## 本地安装

- **Windows**：下载 `TravelerFolio-Windows-Light.zip` 并解压到同一个文件夹后运行 `旅人手札.exe`。如果缺少 WebView2，按启动提示联网安装微软官方运行时，或在浏览器中打开本地卡片；程序不会静默安装系统运行时。公开 Release 不附带约 214 MiB 的离线安装器；本地构建目录保留完整离线包。
- **Android**：安装 `旅人手札-Android.apk`，已有版本直接覆盖安装，不要先卸载。
- **离线 HTML**：也可直接打开 `旅人手札.html`；浏览器角色数据仍保存在原浏览器配置中。

## 验证范围

本地 Edge 浏览器验证了怪物图鉴创建、六区编辑、分类筛选、完整详情、返回编辑和手机宽度布局。模拟多人房间验证了 HP 浮窗、先攻、演出、怪物放置、投骰、目标清除和窗口拖动缩放。Windows 原生启动、桥接及缺少 WebView2 的恢复提示已测试；本地完整包中的 WebView2 安装器微软签名校验通过，该大型安装器不在公开 Release 附件中。

未能从自动化环境进入已登录的真实枭熊房间，因此没有声称真实房间联机验收。本次 Android 模拟器的自动点选在二维码步骤前遇到 UiAutomation 服务错误；APK 版本、原签名和内嵌 HTML 已验证，但本次没有重验扫码端到端流程。实体 Android 手机和不同显卡也需要实际使用者补充验证。

## 后续可选自动化

可以考虑在长休 / 短休时提示结束专注，或在临时状态到期时提示移除。当前版本仍不自动判定命中或扣血，所有伤害需手动应用。
