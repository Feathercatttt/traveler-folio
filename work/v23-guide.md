# 旅人手札 v0.23.0 · 图鉴与枭熊修复

**AI 辅助生成和维护的代码。** 更新前在原版本导出角色备份。APK 使用原签名覆盖安装，保留现有数据。

## 本地安装与更新

- Windows：完整解压 `TravelerFolio-Windows-Light.zip` 后运行 `旅人手札.exe`，保留原来的用户数据目录。完整离线包还附带微软签名的 WebView2 安装器。不要只复制一个 exe。
- Android：覆盖安装 `TravelerFolio-Android.apk`，不要先卸载。
- HTML：直接打开 `TravelerFolio.html`。浏览器数据仍保存在原浏览器配置中；换文件路径前请导出备份。
- 已启用自动更新的 EXE/APK 会通过签名更新清单检查新版本，下载镜像策略沿用上一版。

## 怪物图鉴

左栏“怪物图鉴”打开独立仓库，可按物种、分类、等级和熟练加值搜索筛选。点开怪物卡后，使用“属性总览 / 特性动作 / 物品 / 法术”页签。关闭完全退出界面；“图鉴仓库”返回列表。

特性、物品、法术页签可“从收藏库添加”，默认只列收藏；取消勾选“仅收藏”可搜索完整卡库。复制后的卡片归本怪物独立保存；点击查看、编辑副本、移除，均不修改玩家和原收藏卡。编辑怪物时也可添加收藏卡；取消编辑会丢弃尚未保存的修改。

“制作专属卡”支持名称、描述、消耗标签、物品数量及多条检定/伤害/DC公式。@等级、@熟练、@力量调整等使用本怪物数据。怪物依然不会添加进玩家角色卡。

枭熊“跑团工具 → 怪物”读取图鉴后可准备立绘、放置多个实例。新放置的怪物带有独立 HP、临时 HP、AC、DC，以及自己的特性、动作、物品/法术公式。修改模板不回写地图上的旧实例；HP 只由 Stat Bubbles 记录，所有扣血手动操作。

## 枭熊安装与连接

角色小卡恢复为枭熊原生侧栏窗口：点击扩展按钮开关，使用枭熊原生固定功能；小卡右上角 ＋／− 调整大小，× 关闭。小卡不再带拖动标题栏，也不再自动打开额外的本机连接窗口。

推荐角色速查使用本地插件：每位玩家先打开 v0.23 EXE，再进入房间。DM 在自己的 EXE 开启后安装下列地址，并启用房间扩展：

`http://localhost:17632/manifest.json`

DM 换电脑时也先开 EXE，地址相同。每位玩家读取自己电脑的角色。独立跑团工具可以继续使用 GitHub Pages：

`https://feathercatttt.github.io/traveler-folio/tools-manifest.json`

角色速查线上备用地址仍保留：

`https://feathercatttt.github.io/traveler-folio/manifest.json`

线上小卡会尝试自动读取本机；某些浏览器限制 HTTPS 页面访问 localhost，此时改用上面的本地角色速查即可。停用同类旧扩展后刷新房间，避免本地和线上两套后台重复处理。GitHub Pages 只存插件代码，不存角色资料。

在小卡选择角色，再在地图选中自己的 token，点击“绑定”，同步 HP、临时生命和 AC。其他玩家的本地服务尚未启动时，先开 EXE 再刷新房间。

## 检定与窗口

- 点击检定或公式进入最终确认，可选择优势/劣势、修改骰子/基础公式及临时加值；确认后才掷骰。中文伤害标注可保留。
- 断线时显示重试提示；“取消”和标题栏 × 都可立即关闭。草稿读取暂时失败会重试，避免队列永久卡住。
- 多目标成功掷骰后清除目标；历史保留各目标结果；一次性骰子加成只在成功确认后消耗。目标和伤害结果均不自动扣血。
- 先攻条只在操作按钮、状态小标签和角色条目上保留底色，其余区域完全透明。人数多时只显示部分，滚轮、横向滚动或触控滑动查看，普通刷新保留滚动位置。

## 演出

创建独立演出角色，设置立绘、差分和玩家控制权限；勾选角色后开始直播。控制小窗缩为贴合内容的半透明条，不再填充大片背景。单击角色上场，右键下场；直播期间控制条保留“结束直播”。

直播期间始终允许拖动立绘。DM 或获得该角色控制权限的玩家可直接拖动，松开后位置同步给所有人。按你的选择，演出层会接收地图点击；结束直播后恢复地图操作。没有电影黑条或对话框。
