# 旅人手札 v0.25.1 · 固定先攻、独立图鉴与演出修复

**AI 辅助生成和维护的代码。**

- 跑团工具改为枭熊原生插件面板，像小卡一样点击插件按钮开关，取消可拖动的中转窗口，修复关闭后无法再次打开。
- 先攻条固定在顶部中央下方；头像从 56px 放大到 72px，保持全透明画布。移除先攻加值框和三个投骰按钮；可读取 Stat Bubbles 血条。头像右键可重骰先攻、退出战斗；结束战斗默认清空列表，不删除地图棋子。
- 怪物图鉴与演出直播各有独立地图工具按钮。图鉴初始为空，按名称、种族、分类、等级和熟练加值检索；场上怪物表单独打开，只保留每行名称、HP、临时生命、AC、DC、定位与资料。
- 图鉴放置直接读取已上传立绘，转换为有大小限制的内嵌 WebP 随棋子同步，不使用 DM 电脑的临时图片地址；未设置立绘才调用枭熊图片库选择。新放置的同名怪物默认带 1、2、3 等后缀，地图名称可快速修改。
- 演出角色新增名称搜索与名单筛选；“查看上场名单”在当前面板内筛选，不再打开旧的独立直播浮窗。直播层内始终保留结束按钮，搜索无匹配、删除最后一位角色、空名单时仍可结束并再次开启。
- 修复关闭窗口误用旧窗口标识的问题；取消投骰会先记录取消状态，避免待确认窗口残留或重复弹出。所有伤害仍仅报结果、手动扣血。

实际本地 HTTP 服务、正式打包脚本与真实 Owlbear SDK 在模拟宿主中完成交互测试；Windows 原生启动与 APK 签名/资源校验通过。未登录真实枭熊多人房间进行端到端验证，未使用实体 Android 手机验收。

操作见 [v0.25安装与使用方法](docs/v0.25安装与使用方法.md)。
