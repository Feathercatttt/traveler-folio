# 旅人手札 v0.26.0 · 设置、藏书架与特性编辑整理

**AI 辅助生成和维护的代码。**

- 主界面移除顶部/右侧的备份、打印、风格、更新和浮窗工具，左侧新增“设置”。风格、导出/导入、互通、桌面浮窗、打印、更新与版本集中管理。
- 特性/物品/法术收藏库合并为一个“收藏库”入口，仍在小窗口里切换三类并选择只看收藏；不再包含怪物图鉴入口。
- “藏书架”与“怪物图鉴”改为替换角色卡区域的独立大页面。藏书架按网格整理卡片并提供直接编辑入口；关闭/返回恢复角色卡，保持当前角色。
- EXE 大卡的特性、物品、法术与属性总览支持模糊搜索，点击结果定位并展开；检定结果点击定位，旁边独立骰子按钮才发起检定。枭熊小卡保持原有快速检定方式。
- 角色的特性、物品、法术均可切换只看已收藏，并可在卡片上管理收藏。
- 特性编辑合并基本信息、行动消耗、完整效果和风味文字；可选属性加成收进属性增减，勾选才展开。移除规则备注/自动化说明界面；职业成长来源改为末尾备注内的可选项。编辑备注仅在编辑时显示，支持保存、备份与导入。
- 特性收起时优先预览风味文字，否则截取规则正文；展开后隐藏预览，完整风味和规则各显示一次。

本轮共 43 项检查通过：13 项主界面检查，加上本地插件、Windows 原生、APK 与原有规则/怪物卡回归。真实枭熊多人房间、实体 Android 手机未进行本轮端到端验收。所有伤害仍由用户手动扣除。

使用说明见 [v0.26安装与使用方法](docs/v0.26安装与使用方法.md)。
