# 旅人手札 v0.27.0

修复怪物图鉴无法放置的问题，并增加覆盖场上 token 的路径；修正剧场滤镜的视口采样与合成，直播时可直接切换；检定速查新增可复制的公式示例。

- **上传枭熊并放置**：使用枭熊官方图片上传和选图接口，将图鉴立绘上传为角色图片，再从选图框选择它放置。首次确认后缓存共享 HTTPS 地址，重复放置复用该图片，自动编号。取消选图或上传失败不会创建棋子，旧版内嵌图片缓存不再使用。
- **覆盖选中 token**：先在地图只选中一个图片 token，再点覆盖。更新名称、怪物卡快照、HP/上限/临时 HP、AC、DC，保留图片、位置、缩放、图层、所有者及其他插件数据。玩家卡已绑定的 token 需先解除绑定。
- 两种方式都进入同一份“场上怪物”列表，各实例生命值独立存入 Stat Bubbles；模板和其他怪物生命值不会随之修改。
- **直播滤镜**：全屏滤镜改用视口变换采样，显式替换后处理输出并保留透明度。直播控制条新增“画面滤镜”，DM 可直接切换和恢复原色；结束直播移除本插件的滤镜。
- **公式示例 ƒx**：大卡检定速查与检索栏、枭熊小卡快速检定、表达式投骰及最终确认框均提供小按钮。悬停查看，点击/触屏固定展开，点例子复制；支持键盘与手机可用空间定位。
- 示例包括 `2d20kh1+5`（优势）、`2d20kl1+5`（劣势）、`3d6kh1`（取最大）、`4d6dl1`（丢弃最低）、`1d20+5-1d4`（临时减值）和中文伤害标注。

所有掷骰仍需在最终确认框确认，目标功能不会自动扣血。本地插件随 EXE 同步更新。

**验证范围**：桌面/390px 触屏交互、真实本地服务与 Owlbear SDK 模拟宿主、实际 Skia RuntimeEffect 像素渲染、Windows 原生启动和桥接、APK 签名/资源一致性及原有卡库回归均已检查。未登录真实 Owlbear 多人房间做本轮端到端验收，也未连接实体 Android 手机；真实房间上传权限与 GPU 显示仍需实机复核。
