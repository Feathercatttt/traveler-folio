# 旅人手札 v0.27.1

修复手机版“设置 → 应用与更新”只有标题、没有按钮的问题。

旧版的移动布局样式按按钮 ID 隐藏顶部更新入口。v0.26 将该按钮移入设置后，隐藏规则仍覆盖设置页。现在只隐藏顶部栏中的按钮，设置页显示“检查更新”，可正常打开更新、切换线路、检查版本。

**旧版 APK 的更新入口已被隐藏，因此这次请直接下载新版 APK 并覆盖安装。不要卸载旧版，保留本机角色资料。** APK 继续使用原签名，versionCode 增至 32；以后可在“设置 → 检查更新”操作。

验证包含：先在 v0.27.0 的 Android 桥接环境复现失败，再检查修复后的 360 / 390 / 700 / 844px 触屏设置入口、更新检查与线路保存；生产 APK 签名和 HTML 一致性、Android 15 模拟器真实应用入口与原生更新状态，以及 Windows 原生启动回归。
