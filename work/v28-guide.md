# 旅人手札 v0.28.0

本项目由 AI 辅助编写和维护。

## 安装与更新

- Windows：解压 Windows 轻量包，打开“旅人手札.exe”。缺少 WebView2 时，可用完整包内的微软离线安装器。
- Android：安装新版 APK，覆盖升级保留原有角色数据。
- 离线网页：直接打开“旅人手札.html”。
- 自动更新：手札“设置 → 检查更新”，支持切换下载线路，下载后校验签名和文件。

## 召唤物与怪物装备

1. 召唤物：打开卡片点击“编辑”，或从在场召唤物直接点“编辑”。怪物：打开完整怪物卡点击“编辑”。
2. 展开“装备栏”，勾选“开启此卡装备栏”。默认关闭。
3. “从收藏库添加装备”支持名称模糊搜索；添加后在对应装备位选择。
4. 支持头盔、衣服/护甲、腰带、裤子、鞋子、五个饰品、主手与副手。双手武器占主手，副手需空置。
5. “按装备计算 AC”处理护甲基础、敏捷上限及额外 AC；常驻数值影响随穿戴生效，卸下即取消。“装备数值来源”可展开查看。
6. 装备中已有的属性引用按穿戴者的属性、等级和熟练加值计算。武器攻击与伤害公式同步到速查。
7. 召唤物模板和每次召唤各自保存装备。编辑模板不会改动已经召唤的对象。取消编辑不保存草稿。
8. 怪物装备位于完整卡的“物品 / 装备”页。地图怪物在放置或覆盖时取得装备后的数据；已放置怪物的 HP、临时 HP、AC 仍由 Stat Bubbles 独立记录。

关闭装备栏会暂停装备影响，保留选择，重新开启可继续使用。召唤物生命上限降低时，当前生命最多保留到新上限。

## 枭熊

每位使用者先打开自己电脑上的 EXE；DM 在房间启用这两个插件：

- 角色小卡：`http://localhost:17632/manifest.json`
- 跑团工具：`http://localhost:17632/tools-manifest.json`

手札更新后，重新打开 EXE 并刷新枭熊房间即可加载新版。GitHub 安装页仅作说明和兼容入口。

公式点击后先打开掷骰草稿，可以修改公式、临时加值及优势/劣势，再确认投骰。目标选择和掷骰不会自动扣血。

怪物图片流程：上传立绘 → 在枭熊选图并绑定 → 查看预览 → 放置。也可选一个现有 token 覆盖怪物数据。场上列表可改名称、HP、临时 HP、AC、DC，并定位。

## 本次整理

减少复杂卡片预览的重复计算和无关扫描；小卡不因其他仓库数据变化重复重建。安装包只保留本说明与必要许可证。更新器会将明确列出的旧版说明移入更新备份，不处理用户自行编写的文本。
